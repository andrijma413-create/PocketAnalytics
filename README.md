# 📈 PocketAnalytics (LIVE FX v13)

**PocketAnalytics** — це веб-додаток для технічного аналізу валютних пар та торгових активів у реальному часі. Інструмент розроблений для швидкого моніторингу ринку, аналізу графіків та отримання торгових сигналів прямо у браузері.

🚀 **[Запустити PocketAnalytics (LIVE FX)](https://andrijma413-create.github.io/PocketAnalytics/)**

---

## 🛠 Основні можливості

* **LIVE Графіки:** Відстеження динаміки цін у режимі реального часу.
* **Технічні індикатори:**
  * **RSI (Relative Strength Index)** — визначення зон перекупленості та перепроданості.
  * **MACD** — аналіз тренду та моментів розвороту.
  * **Bollinger Bands** — оцінка волатильності ринку.
  * **Stochastic Oscillator & Williams Fractals** — додаткові сигнали для точок входу.
  * **EMA Crossovers (9 / 21)** — перетин ковзних середніх для підтвердження тренду.
* **Адаптивний інтерфейс:** Зручна робота як з ПК, так і з мобільних пристроїв.

## 🚀 Як запустити проєкт

Проєкт не потребує встановлення додаткових залежностей чи серверного середовища:

1. Перейдіть за [онлайн-посиланням на GitHub Pages](https://andrijma413-create.github.io/PocketAnalytics/).
2. Або завантажте файл `PocketAnalytics_LIVE_FX_v13.html` та відкрийте його у будь-якому сучасному браузері.
